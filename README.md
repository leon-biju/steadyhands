# steadyhands

Start the project with `npx vite`

- Game: http://localhost:5173
- Hand tracking + calibration + test panel: http://localhost:5173/input-debug.html (allow camera access)
- Same page with the mouse: http://localhost:5173/input-debug.html?input=mouse

Our project, SteadyHands, made a game where the goal is to navigate managing a nuclear FUSION reactor’s temperature and pressure to avoid a nuclear meltdown using hand symbols. Our project uses computer vision to track the users hand symbols through their webcam and the current position of them. During this, the user encounters many obstacles and unexpected events. To run this clone the project from the github and run npx vite on the terminal to allow you to run it from your browser on localhost.
